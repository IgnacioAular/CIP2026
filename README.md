## Final Project - Detailed Description:

Project Description: Purchase Simulator with Exact Change

Overview:
The Purchase Simulator with Exact Change is a program designed to simulate a purchase transaction and calculate the exact change a cashier should return to a customer using
available denominations of bills and coins. This project combines fundamental programming concepts such as loops, conditionals, arithmetic operations, and data structures 
like lists and dictionaries.

How It Works:

The program prompts the user to input the total cost of the purchase and the amount paid by the customer.
It verifies whether the payment is sufficient. If the payment is less than the total amount, it informs the user of the shortfall.
If the payment is sufficient, it calculates the total change to return.
Using a predefined list of available denominations in descending order (from largest to smallest), the program determines how many of each bill or coin
should be returned to the customer.
Finally, it provides a detailed breakdown of the exact bills and coins to give back, ensuring minimal denominations are used.

Key Features:

Handles insufficient payment scenarios.
Returns change using the optimal combination of bills and coins.
Easily extensible to include additional denominations, including coins.
Uses simple, readable Python code with clear logic.

Data structures like lists and dictionaries for organizing denominations and tracking change.
User input validation and program flow control.

I also learned the importance of thinking from a user’s perspective. For example, presenting a clear breakdown of the change ensures the program is practical
